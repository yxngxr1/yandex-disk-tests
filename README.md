## Описание
Тестовое задание для отбора на стажировку в Яндекс.Диск. Пример проекта автотестов для открытого Api Диска ([документация](https://yandex.ru/dev/disk/rest)).  
Стек: **Python: pytest · pytest-html · requests · pydantic · python-dotenv**

---

## Воспроизведение

0. **Установите python:**
   - Установите **Python 3.10+** ([официальный сайт](https://www.python.org/downloads/))  
   - Получите **OAuth‑токен** для Яндекс.Диск ([дайте два](https://yandex.ru/dev/disk-api/doc/ru/concepts/quickstart))

1. **Клонируйте репозиторий:**

   ```bash
   git clone https://github.com/yxngxr1/yandex-disk-tests.git
   cd yandex-disk-tests
    ```

2. **Создайте и активируйте виртуальное окружение:**
    ```bash
    python -m venv .venv
    ```
    | OS | Команда активации |
    |----------------------|-------------------|
    | macOS / Linux (bash, zsh) | `source .venv/bin/activate` |
    | Windows (cmd) | `.venv\Scripts\activate.bat` |
    | Windows (PowerShell) | `.venv\Scripts\Activate.ps1` |

3. **Установите зависимости:**
    ```
    pip install -r requirements.txt
    ```

4. **Задайте переменные окружения:**
Создайте .env в корне проекта по примеру с .env.example.  
Вставьте OAUTH_TOKEN

## Запуск тестов

```bash
# Все тесты
pytest

# С генерацией HTML‑отчёта
pytest --html=report.html --self-contained-html

# Запуск конкретного теста
pytest tests/v1/endpoints/test_resources_get.py

# Запуск с определённой маркировкой
pytest -m positive
```

## Покрытие API

Типы: P - позитиынй кейс, N - негативный.

#### GET /v1/disk - метаинформация о диске

| Тип | Сценарий                                    | Ожидаемый код |
|-----|---------------------------------------------|---------------|
| P   | Получение метаинформации                    | 200           |

#### GET /v1/disk/resources - получение мета

| Тип| Сценарий                          | Ожидаемый код |
|----|-----------------------------------|---------------|
| P  | Существующая папка                | 200           |
| P  | Существующий файл                 | 200           |
| P  | Фильтрация полей (`fields`)       | 200           |
| P  | Корневая папка `/`                | 200           |
| N  | Несуществующий ресурс             | 404           |
| N  | Без обязательного параметра `path`| 400           |
| N  | Без авторизации                   | 401           |


#### PUT /v1/disk/resources — создание папки

| Тип | Сценарий                                             | Ожидаемый код |
|-----|------------------------------------------------------|---------------|
| P   | Успешное создание папки                              | 201           |
| P   | Фильтрация полей (`fields`)                          | 201           |
| P   | Создание вложенной папки в существующую              | 201           |
| N   | Папка уже существует                                 | 409           |
| N   | Без параметра `path`                                 | 400           |
| N   | без авторизации                                      | 401           |

#### DELETE /v1/disk/resources — удаление файла или папки

| Тип | Сценарий                                             | Ожидаемый код |
|-----|------------------------------------------------------|---------------|
| P   | Успешное удаление папки в корзину                    | 204           |
| P   | Успешное удаление папки минуя корзину                | 204           |
| N   | Удаление несуществующего ресурса                     | 404           |
| N   | Удаление без авторизации                             | 401           |

#### POST /v1/disk/resources/copy — копирование файла или папки

| Тип | Сценарий                                    | Ожидаемый код |
|-----|---------------------------------------------|---------------|
| P   | Успешное копирование папки                  | 201           |
| P   | Успешное копирование файла                  | 201           |
| N   | Без параметра `path`                        | 400           |
| N   | Копирование без авторизации                 | 401           |
| N   | Копирование несуществующего ресурса         | 404           |
